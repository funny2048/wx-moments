# 外部服务集成约束

> 需求探索阶段逐项检查。全公司 Java 项目通用。

## 规则

1. **视频上传** → 必须对接**视频中心**获取 `mediaId`，禁止自行存储视频或生成媒体 ID。
2. **广告素材图片** → 必须经 **ADM 存储桶**上传，禁止存业务库/本地文件系统。

## 触发词检查

需求中出现以下词时，对照上述规则：

| 关键词 | 检查 |
|--------|------|
| 视频/上传/播放/转码 | 是否对接视频中心？ |
| 图片/素材/广告/海报/封面 | 是否走 ADM S3？ |
| 文件/附件/下载 | 存储方案是什么？ |

## 扩展

新增公司级约束在本文件末尾追加：`## N. 服务名` + 规则 + 原因。
